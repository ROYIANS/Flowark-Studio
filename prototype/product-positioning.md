# Flowark Studio 产品定位文档

> **最后更新**: 2025-01-25
> **版本**: v2.0 - 重大更新（增加社区和商业化）

---

## 📍 核心定位

### 一句话定位

**Flowark 是一个文学杂志风的创作-发布一体平台，让拥有独特品味的创作者用 AI 放大他们的光芒，并通过优质内容获得收益。**

### 产品公式

```
Flowark =
  私域创作工具 (Studio with AI)
  + 公域内容社区 (Magazine-style Community)
  + 创作者经济平台 (Subscription & Monetization)
```

---

## 🎯 产品愿景

> "AI 拉高了创作的下限，但也正在摧毁创作的上限。Flowark 的使命是让拥有独特品味的人，用 AI 放大他们的光芒。"

### 时代的痛点

在 AI 时代，技能（手）的门槛被极度拉平，但眼界（品味）却面临被算法平均化、平庸化的风险：

- **现状**: 用户依赖 AI 一键生成，导致内容千篇一律，丧失个人特质
- **后果**: 创作者沦为 AI 的"快捷键操作员"，自身的创作能力和审美逐渐退化
- **变现困境**: 优质创作者在传统平台难以获得与内容质量匹配的收益

### Flowark 的解决方案

**三位一体的价值闭环**:

```
1. 创作赋能 (Studio)
   ├─ AI 辅助但不替代
   ├─ 品味建模和成长
   └─ 沉浸式创作体验

2. 内容分发 (Community)
   ├─ 文学杂志风展示
   ├─ 品味匹配推荐
   └─ 精致的阅读体验

3. 价值变现 (Monetization)
   ├─ 会员订阅制
   ├─ 创作者收益分成
   └─ 多元化收入来源
```

## 👥 目标用户

### 核心用户画像

#### 用户 A: 独立创作者 (Primary)

**特征**:
- 25-40 岁，有一定文字功底
- 在其他平台有少量粉丝（100-10,000）
- 追求内容质量而非流量
- 对排版和美学有要求
- 希望通过创作获得收益

**痛点**:
- 在流量平台难以获得曝光（不会做标题党）
- 优质内容被淹没
- 现有工具要么太简陋（公众号），要么太复杂（Notion）
- 变现困难，收入与质量不匹配

**Flowark 的价值**:
- 专业的创作工具（AI 辅助）
- 高品味的读者社区
- 公平的收益分配（按阅读时长）
- 精美的内容展示

---

#### 用户 B: 品味读者 (Secondary)

**特征**:
- 25-45 岁，受过高等教育
- 喜欢深度阅读
- 反感标题党和浅薄内容
- 愿意为优质内容付费
- 追求阅读体验和美学

**痛点**:
- 在信息洪流中找不到优质内容
- 传统平台推荐算法低质化
- 阅读体验差（排版乱、广告多）

**Flowark 的价值**:
- 策展的优质内容
- 极致的阅读体验
- 一次付费，畅读全站
- 支持喜爱的创作者

             │ 一键发布（可选）

┌─────────────────────────────────────┐

│  • 杂志风首页                        │

### URL 架构

```
# 公域 (Community) - 所有人可访问
flowark.com                          → 社区首页
flowark.com/article/[id]             → 文章阅读页
flowark.com/@[username]              → 用户的公开书架
flowark.com/@[username]/[slug]       → 用户的某篇文章

# 私域 (Studio) - 仅登录用户可访问
flowark.com/studio                   → 工作室首页
flowark.com/studio/editor/[id]       → 编辑器
flowark.com/studio/personas          → 人设管理
flowark.com/studio/insights          → 品味洞察
flowark.com/studio/earnings          → 收益中心

# 账户
flowark.com/auth/login               → 登录
flowark.com/auth/signup              → 注册
flowark.com/settings                 → 设置
```

## 🔄 核心流程

### 创作-发布流程

```
1. 注册成为创作者
   ↓
2. 创建人设档案
   ↓
3. 在 Studio 编辑器写作
   ├─ AI 辅助（润色、建议）
   ├─ 品味印记记录
   └─ 自动保存草稿
   ↓
4. 点击"发布"
   ├─ 选择：发布到社区 or 仅私密
   ├─ 选择：访问权限（公开/会员专享/单篇付费）
   ├─ 设置：封面、分类、标签、摘要
   └─ 可选：同步到外部平台
   ↓
5. 发布成功
   ├─ 出现在社区首页
   ├─ 出现在个人书架
   └─ 开始累积阅读时长
   ↓
6. 获得收益
   ├─ 会员阅读 → 会员池分成
   ├─ 读者打赏 → 直接收入
   └─ 单篇付费 → 90% 归创作者
```

### 阅读-订阅流程

```
1. 访问 flowark.com
   ↓
2. 看到精心策展的内容
   ├─ 杂志风布局
   ├─ 编辑精选
   └─ 品味匹配推荐
   ↓
3. 点击文章阅读
   ├─ 公开文章：完整阅读
   ├─ 会员文章：显示 30%，后续模糊
   └─ 付费文章：显示 20%，后续模糊
   ↓
4. 遇到会员内容
   ├─ 提示：成为会员解锁全站内容
   ├─ 价格：¥25/月 或 ¥240/年
   └─ 价值：支持创作者 + 畅读全站
   ↓
5. 订阅会员
   ├─ 微信支付/支付宝
   ├─ 立即解锁所有会员内容
   └─ 阅读时长自动记录
   ↓
6. 深度阅读
   ├─ 喜欢、收藏、评论
   ├─ 打赏喜爱的创作者
   └─ 发现更多优质内容
```

## 🎨 设计哲学

### 温暖杂志极简主义

**四大核心关键词**:
- **温暖 (Warmth)**: 暖色调，避免冷蓝和深黑
- **呼吸 (Breathing)**: 大量留白，让界面有呼吸感
- **去框化 (De-boxing)**: 能用留白和线条的，绝不使用卡片容器
- **纸感 (Paper-like)**: 模拟纸张质感，营造自然书写体验

### 色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| Canvas | `#FDFCF8` | 背景色（暖白纸张） |
| Terracotta | `#E86435` | 主色（陶土橙） |
| Terracotta Hover | `#F2E8E3` | 悬停/次级色 |
| Text Primary | `#2D2A26` | 主要文本（近黑暖调） |
| Text Secondary | `#8E8780` | 次要文本（暖灰） |
| Divider | `#EBE5E0` | 分割线（极淡暖灰） |

### 排版规范

- **标题**: Serif (衬线体) - 营造杂志高级感
- **正文**: Sans-serif (无衬线体) - 保证清晰阅读
- **去卡片化**: 使用 HoverRow，全宽布局，只有上下分割线

**详见**: `docs/design/UI.md`

## 🚀 五条避坑铁律

基于对市场竞品（尤其是失败案例）的深度分析，我们制定了五条产品设计铁律：

| 铁律 | 说明 | 体现 |
|------|------|------|
| **永远不要"替用户做决策"** | AI 只提供选项和参考，最终决策权在用户 | AI 给出 3 个标题让用户选，而非直接替换 |
| **永远不要割裂流程** | 整个创作在一个沉浸式编辑器完成 | 不弹窗，侧边栏展示 AI 建议 |
| **永远不要用"复杂表单"** | 能用"选择"的，绝不用"输入" | 3 秒选择题，而非长文本输入框 |
| **永远不要做"一次性输出"** | 每次交互都要喂养品味模型 | 用户每次选择都记录为品味印记 |
| **永远不要"为了AI而AI"** | AI 只在关键时刻出现 | 默认隐藏 AI 侧边栏，按需唤起 |

## 💰 商业模式

### 收入来源

```
1. 会员订阅 (70-80%)
   ├─ 月度会员: ¥25/月
   ├─ 年度会员: ¥240/年
   └─ 平台抽成: 15%

2. 创作者打赏 (10-15%)
   └─ 平台抽成: 10%

3. 单篇付费 (5-10%)
   └─ 平台抽成: 10%

4. 企业授权 (未来)
   ├─ 私有部署
   ├─ 白标定制
   └─ 插件市场分成
```

### 收益分配

```
会员费池分配（每月1号结算）:
├─ 85% → 创作者池
│   └─ 按阅读时长占比分配
└─ 15% → 平台运营

创作者收益来源:
├─ 会员池分成（按阅读时长）
├─ 读者打赏（90% 归创作者）
└─ 单篇付费（90% 归创作者）
```

## 🌟 品牌调性

### 关键词

- **温暖** - 不是冷冰冰的科技产品
- **品味** - 高品质，有审美
- **克制** - 不追逐流量，不制造焦虑
- **文学** - 杂志感，艺术感
- **真诚** - 不套路，不操纵

### Slogan

- **对外**: "用品味放大创作，用 AI 成就更好的自己"
- **对创作者**: "专注创作，让品味发光"
- **对读者**: "在这里，深度阅读不是奢侈品"

### 语气 (Tone of Voice)

- ✅ 温暖、友好、专业
- ✅ 鼓励、启发、尊重
- ❌ 避免：焦虑营销、浮夸、居高临下
